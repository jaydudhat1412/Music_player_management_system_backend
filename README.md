🎵 Music Player Management System

A Java-based, terminal-driven Music Player Management System developed as our Semester 2 project. This project combines Java programming, Data Structures, DBMS, JDBC connectivity, and Spotify API integration to provide music playback and management features.

🚀 Project Overview

The Music Player Management System allows users to search for music through Spotify integration, play songs, navigate between tracks using a queue, manage favourite songs, and handle music downloads. It also includes an admin panel for managing songs and related system operations.

The application runs in the terminal/console, not through a graphical user interface (GUI).

✨ Key Features

- 🎧 Spotify API Integration — Search for music and integrate Spotify functionality.
- ▶️ Music Playback Controls — Play, pause, next, and previous song controls.
- 📋 Queue Management — Use Data Structures to manage the song queue and navigate between tracks.
- ❤️ Favourite Songs — Add, view, and manage favourite songs.
- 📥 Download Management — Manage the project's supported music download functionality.
- 🛠️ Admin Panel — Manage songs, users, downloads, and other system operations.
- 🗄️ Database Management — Store and manage data using MySQL and phpMyAdmin.
- 🔗 JDBC Connectivity — Connect the Java application with the database.
- 💻 Terminal-Based Interface — Interact with the application through a console menu.

🛠️ Technologies Used

- Java — Core application development
- Data Structures — Queue implementation for song navigation
- DBMS — Database design and management
- MySQL — Database storage
- phpMyAdmin — Database administration

⚙️ Prerequisites

Before running the project, make sure you have:

- Java Development Kit (JDK)
- MySQL Server
- phpMyAdmin (for database management)
- The required JDBC driver
- Spotify API credentials, if required by the implementation

📥 Installation and Setup

1. Clone the Repository

git clone https://github.com/jaydudhat1412/Music_player_management_system_backend.git

Navigate to the project directory:

cd Music_player_management_system_backend

2. Set Up the Database

1. Start your MySQL server.
2. Open phpMyAdmin.
3. Create the database required by the project.
4. Import the project's SQL file if one is available.
5. Configure the database connection details in the Java application.

3. Configure Spotify API

1. Create an application in the Spotify Developer Dashboard if required.
2. Configure the necessary API credentials according to the project implementation.
3. Keep API secrets and passwords private. Do not upload them to GitHub.

4. Configure JDBC

Ensure that the appropriate JDBC driver is available and that the database URL, username, and password match your local configuration.

5. Run the Application

Open the project in your preferred Java IDE and run its main Java class. Make sure the required database, JDBC driver, and API dependencies are configured correctly.

Note: The exact main class, database name, and run command depend on the source code and configuration included in the repository.
